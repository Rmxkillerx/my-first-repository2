# PUBG WireGuard Tester — مشروع Android أولي

مشروع مصدر لتطبيق Android يدمج مكتبة WireGuard الرسمية. يتيح استيراد ملفات `.conf` متعددة، وتشغيل أول ملف، وإجراء Ping لعناوين IP، وقياس سرعة HTTPS عبر Cloudflare.

## البناء
1. فك ضغط الملف.
2. افتح مجلد `PUBG_WireGuard_Tester` في Android Studio حديث.
3. استخدم JDK 17 وانتظر Gradle Sync.
4. اختر Build > Build APK(s).
5. APK التجريبي يظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## حدود النسخة الحالية
- هذه ملفات مصدر وليست APK مبنية أو مختبرة على هاتف فعلي.
- النسخة الحالية تشغّل أول ملف مستورد فقط؛ التبديل التلقائي والاختبار المتتابع لكل الملفات لم يكتمل بعد.
- Ping يعتمد على أمر `ping` في Android؛ قد تحجب بعض خوادم PUBG طلبات ICMP.
- قياس السرعة يستخدم Cloudflare عبر HTTPS. يجب أن يمر مسار الإنترنت في ملف WireGuard عبر النفق (عادة `AllowedIPs = 0.0.0.0/0, ::/0`) وإلا فقد تقيس الاتصال العادي.
- ملفات الإعدادات ومفاتيحها تُقرأ محلياً ولا تُرسل إلى خادم تابع لهذا المشروع. لا تشارك ملفات `.conf` لأنها تحتوي مفاتيح خاصة.
- عناوين IP الخاصة باللعبة قد تتغير حسب المنطقة والجلسة؛ الاختبار على عنوان قديم لا يضمن قياس خادم المباراة الحالي.

## المكتبة
`com.wireguard.android:tunnel:1.0.20260102` — المكتبة الرسمية القابلة للدمج في تطبيقات Android.


## بناء APK عبر الإنترنت دون تثبيت Android Studio
أضيف ملف GitHub Actions في `.github/workflows/android-build.yml`.
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد بعد فك الضغط إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب Actions ووافق على تفعيل workflows إن طُلب.
4. شغّل `Build Android APK` من Run workflow، أو ادفع commit إلى فرع main.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى Artifacts لتحميل `PUBG-WireGuard-Tester-debug-apk`.
